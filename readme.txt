EPDC Conversations provides a lightweight, conversion-oriented foundation for WhatsApp CTA workflows.

== Description ==
EPDC Conversations provides:

* Floating and inline WhatsApp CTAs
* Settings-driven defaults with shortcode and block overrides
* Server-side rendered output with minimal frontend JavaScript
* Anonymous click tracking with hashed IP storage
* Lightweight analytics screens for internal reporting

== Installation ==
1. Upload the plugin files to `/wp-content/plugins/epdc-conversations`.
2. Run `composer install` when installing from source.
3. Activate the plugin through the 'Plugins' screen in WordPress.
