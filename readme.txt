EPDC Conversations provides a lightweight, conversion-oriented foundation for WhatsApp CTA workflows.

== Description ==
Initial plugin scaffold with service-based architecture, admin settings placeholder,
frontend renderer placeholder, and extensibility-ready structure.

== Installation ==
1. Upload the plugin files to `/wp-content/plugins/epdc-conversations`.
2. Activate the plugin through the 'Plugins' screen in WordPress.
